# 星烛学院：缄默夜

加到主屏幕就能玩的密室。地址是 [https://fengyanz.com/escape/](https://fengyanz.com/escape/)。

你扮演一年级学生林小烛。缄默夜锁上了西翼，活楼梯停在半空。四间屋子，第三人称点地走路。谜题都是逻辑题，线索在房间里，卡住可以看三层提示。

和哈利·波特没有关系：没有那个世界的人名、地名和情节。学院、咒语规矩和角色都是新的。

## 在 iPhone 上装成一个 App

1. 用 Safari 打开 `https://fengyanz.com/escape/`
2. 点底部分享按钮
3. 选「添加到主屏幕」
4. 以后从主屏幕进，全屏，断网也能玩

声音默认关着。右上角「声音关」点一下才出声。进度在这台手机的本地存储里，菜单里可以重新开始。

## 改哪里

不需要构建。GitHub Pages 直接托管这些静态文件。

| 想改什么 | 文件 |
| --- | --- |
| 房间地图、门、家具位置 | `js/data/rooms.js` |
| 文案、谜题答案、提示、物品、对话 | `js/data/world.js` |
| 谜题判定 | `js/game/logic.js` |
| 画面 | `js/render/art.js`、`js/render/scene.js` |
| 界面 | `js/game/ui.js`、`css/game.css` |

地图字符：`#` 高墙，`=` 矮栏，`.` 地面，`+` 门洞。北是 y 小的一侧。

改了谜题规则，请一起改 `test/logic.test.mjs` 里对应的约束，然后在仓库根目录跑：

```bash
node --test escape/test/logic.test.mjs
```

本地预览时，在仓库根目录起一个静态服务器，再打开 `/escape/`（不要用 `file://`，模块和服务工线程需要 http）：

```bash
python3 -m http.server 8765
```

开发时打开 `/escape/?dev=1`，控制台里有 `window.__game`。

离线缓存的文件列表在 `sw.js` 的 `ASSETS`。换了资源就把 `CACHE` 的版本号加一。

## 通关（剧透）

下面是完整顺序。自己玩的话先别看。

1. 烛火中庭。青铜碑的四条规矩只有一个解：墨、银、金、铜。走到厅心星形砖，按这个次序点亮。东门打开。
2. 壁炉里拿走星烬。南栏旁边的裂砖下有钥匙齿。
3. 回响书廊。四本书从左到右：甲是史录（褐封面、日纹、2 扣），乙是星图（绛、羽、3 扣），丙是阶咒（青、钥、4 扣），丁是药剂（白、月、1 扣）。到对题台提交。丙册夹层里有钥匙柄。
4. 打开随身物，把钥匙齿和钥匙柄拼成铜钥。
5. 残页。彩窗上的别名：墨→羽，银→月，金→烛，铜→钟。按烛的苏醒顺序，钥匙是羽、月、烛、钟。沿星律环往回退，得到「正中是烛或是钟」。
6. 北门进药剂回廊。坩埚按这个次序：星烬、鸦羽灰、铜锈。得到澄星液。
7. 星钟塔。把澄星液浇在石面隐去的那一行，显出「羽不与钥相邻」。
8. 归名星盘从左到右：钟、钥、烛、月、羽。天亮，楼梯会动。
